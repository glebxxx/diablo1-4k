# Paths removed from the upstream DevilutionX tree when building devilutionx/.

# Read by scripts/sync-upstream.sh. Format:
#   - one path per line, relative to the upstream repository root;
#   - a trailing "/" marks a directory (informational only);
#   - no globs, no "..", no absolute paths;
#   - "#" starts a comment, blank lines are ignored.
#
# Rule of thumb: remove only what is NOT needed to configure, build, test
# and run DevilutionX on macOS (x86_64 + arm64). Never prune Source/: our
# patches must keep applying to pristine upstream sources, and platform
# code there is guarded by #ifdef anyway. Never prune LICENSE.md, README.md
# (it carries upstream's legal notices) or Packaging/resources/ (third-party
# license texts for the shipped app).
#
# Verified at upstream 452eeccc: the pruned tree configures, builds, runs
# `--version`, and builds the unit tests (see docs/BUILDING-macOS.md).
